Talk to this outline. Screen: sign-in → workspace → share → import.

   “This is Commons, a scoped collaborative doc for the Ajaia take-home. I did not rebuild Google Docs. I shipped create, edit, persist, import, and share.”

2. **Sign in as Alex (20s)**  
   Show seeded accounts. Password `commons-demo`. Enter workspace.

3. **Editing (45s)**  
   Open Welcome to Commons. Rename the title. Bold / heading / list. Point at the Saved indicator. Refresh the page. The document is still there.

4. **Owned vs shared (40s)**

6. **File import (30s)**  
   Import a `.md` or `.txt`. Show the type list in the UI. Open the new document. Mention attachments as the second file path.

7. **Cuts and AI (40s)**  
   “I cut realtime, comments, and version history. Access rules are unit-tested. AI wrote boilerplate; I rejected a full clone and generic SaaS chrome. Details in AI_WORKFLOW.md.”
